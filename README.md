# 🐍 Python Practice Lab

A practical repository for learning Python, Data and Artificial Intelligence through theory, exercises and projects.

## 📖 About This Repository

**Python Practice Lab** is a personal learning repository that grows alongside my studies in **Artificial Intelligence and Big Data**.

I regularly add new content based on the topics I study during my specialization, expanding them with additional explanations, examples, exercises and information from other learning resources.

To make the learning process more engaging, many exercises and projects are inspired by **MMORPG-style videogames such as World of Warcraft**, using familiar concepts like characters, levels, health, damage, experience, quests and inventories to practice programming concepts in a more visual and entertaining way.

## 🧠 Learning Approach

Each topic follows the same practical structure:

📖 **Theory** - Understand the concepts with simple explanations and examples.

🧩 **Exercises** - Reinforce them through exercises of increasing difficulty.

🚀 **Project** - Apply everything learned in a small module project.
